មគ្គុទ្ទេសក៍នេះណែនាំជំហានម្ដងមួយៗ ដើម្បីបង្កើតឆាក **Barefoot Dancer** ឡើងវិញ — គោលបំណងគឺផ្ដល់ចំណេះដឹងមូលដ្ឋានដែលអ្នកអាចពង្រីកបន្តបាន។ វាមិនពន្យល់ស៊ីជម្រៅអំពីដំណើរការនីមួយៗទេ — សម្រាប់ព័ត៌មានលម្អិត សូមមើលមគ្គុទ្ទេសក៍អ្នកប្រើប្រាស់ (ជំពូក ១–៨ នៃគេហទំព័រនេះ)។

តម្រូវការ
----------

ដើម្បីអនុវត្តតាមមគ្គុទ្ទេសក៍នេះ អ្នកត្រូវការ៖

- Daz Studio 4.6 ឬខ្ពស់ជាង
- **Genesis 2 Female Starter Essentials**
- **Default Lights and Shaders for DAZ Studio**

សូមមើលអត្ថបទ `Downloading with Install Manager <https://docs.daz3d.com/public/software/install_manager/userguide/use_install_manager/tutorials/download_content_with_im/start>`_ ដើម្បីដឹងពីរបៀបទាញយក និងដំឡើងផលិតផលទាំងនេះតាមរយៈ Daz Install Manager។

.. tip::

   នៅកំណែថ្មីៗ មាតិកា Starter Essentials សម្រាប់តួជំនាន់ក្រោយ (Genesis 8/9) ក៏អាចប្រើតាមជំហានដូចគ្នានេះដែរ — គ្រាន់តែជ្រើសមាតិកាដែលត្រូវនឹងតួរបស់អ្នក។

ជំហានទី ១ — ត្រៀម Interface Layout
-------------------------------------

Daz Studio មាន «Interface Layouts» ជាច្រើន។ មេរៀននេះប្រើ layout **Hollywood Blvd** ដែលជា layout លំនាំដើម។ បើនេះជាលើកទី ១ របស់អ្នកក្នុងការបើក Daz Studio (ឬអ្នកមិនធ្លាប់ប្ដូរ layout) អ្នកមិនចាំបាច់ធ្វើអ្វីបន្ថែមទេ។

បើធ្លាប់ប្ដូរ layout រួចហើយ សូមប្ដូរទៅ Hollywood Blvd វិញ៖ ចូល **Window > Workspace > Select Layout…** រួចជ្រើស **Hollywood Blvd** ពីម៉ឺនុយធ្លាក់ចុះ ហើយចុច **Accept**។

Layout នេះបែងចែកជា «Activities» ជាច្រើន — អ្នកអាចប្ដូររវាង Activities ដោយចុចលើ «Activity Tabs» នៅផ្នែកខាងលើនៃ Main Window។

ជំហានទី ២ — ផ្ទុកតួ សម្លៀកបំពាក់ សក់ និងបរិស្ថាន
------------------------------------------------------

ចាប់ផ្តើមដោយចូល Activity **Actors, Wardrobe & Props** (ចុចលើ Activity tab)។

តួអង្គ (Actor)
~~~~~~~~~~~~~~~

#. បើកផ្ទាំង **Smart Content** ដោយចុចលើ tab «Smart Content» នៅខាងឆ្វេងនៃចំណុចប្រទាក់ ហើយប្រាកដថា page **Files** នៅផ្នែកខាងលើត្រូវបានជ្រើស។
#. ពង្រីក category **Figures** ដោយចុចព្រួញនៅខាងឆ្វេង រួចពង្រីក subcategory **People** និងជ្រើស **Female**។
#. រូបភាពតំណាងនឹងលេចឡើងនៅជួរខាងស្ដាំ។ ចុចពីរដងលើ **FIGURE - Barefoot Dancer** ដើម្បីផ្ទុកតួចូលឆាក — អ្នកនឹងឃើញវាលេចឡើងក្នុង Viewport ជាមួយ Bounding Box ដែលបញ្ជាក់ថាវាកំពុងត្រូវបានជ្រើស។

សម្លៀកបំពាក់ (Wardrobe)
~~~~~~~~~~~~~~~~~~~~~~~~

ពង្រីក category **Wardrobe** រួចជ្រើស **Full-Body**។ ចុចពីរដងលើ **CLOTHING - Barefoot Dancer** ដើម្បីផ្ទុកសម្លៀកបំពាក់ ឬអូសរូបភាពតំណាងទៅដាក់លើតួក្នុងឆាកក៏បាន។

សក់ (Hair)
~~~~~~~~~~~

ពង្រីក category **Hair** រួចជ្រើស subcategory **Short**។ ផ្ទុក **HAIR - Toulouse Hair** ដោយចុចពីរដង ឬអូសទម្លាក់លើតួ Barefoot Dancer។

បរិស្ថាន (Environment)
~~~~~~~~~~~~~~~~~~~~~~~~

#. ដំបូង **ដកការជ្រើស (Deselect)** តួសិន — ចុចនៅកន្លែងណាមួយក្នុង Viewport ដែលមិនចំតួ ឬសម្លៀកបំពាក់។
#. ពង្រីក category **Ready to Render** រួចជ្រើស **Architecture**។
#. ចុចពីរដងលើ **ENVIRONMENT - Barefoot Dancer** ដើម្បីផ្ទុកបរិស្ថានចូលឆាក។

.. important::

   ការជ្រើសវត្ថុក្នុងឆាកសំខាន់ណាស់ — រាល់ពេលចង់កែវត្ថុណាមួយ អ្នកត្រូវជ្រើសវាជាមុនសិន។ ដើម្បីជ្រើសសក់ ឧទាហរណ៍ ចុចស្ដាំលើសក់ក្នុង Viewport រួចជ្រើស **Select 'ToulouseHR'** ពី Context Menu — Bounding Box នឹងលេចឡើងជុំវិញសក់។

ជំហានទី ៣ — កែរូបរាងសក់ (Shaping)
------------------------------------

#. ចុច tab **Shaping** នៅខាងឆ្វេងនៃចំណុចប្រទាក់ (ផ្ទាំងនេះជាប់គ្នានឹង Smart Content)។
#. ចុច **Presets** នៅផ្នែកខាងលើនៃផ្ទាំង ដើម្បីបើក page Presets។
#. ចុច category **Apply** នៅខាងឆ្វេង រួចចុចពីរដងលើរូបភាពតំណាង **HAIR SHAPE - Toulouse Hair** នៅខាងស្ដាំ ដើម្បីអនុវត្ត។

ជំហានទី ៤ — បង្កើតកាយវិការ (Pose)
-------------------------------------

#. បើក Activity **Pose & Animate** ដោយចុចលើ Activity tab។
#. ជ្រើសតួ Barefoot Dancer៖ ដាក់ទ្រនិចកណ្ដុរលើតួរហូតដល់វាលេចពណ៌ រួចចុចពីរដង (ឬចុចស្ដាំ រួចជ្រើស **Select 'Genesis 2 Female' - Dbl Click**)។
#. បើកផ្ទាំង **Posing** (tab នៅខាងឆ្វេង) រួចចុច **Presets**។
#. ពង្រីក category **By Function** រួចជ្រើស subcategory **Running**។
#. ចុចពីរដងលើ **Pose - Genesis 2 Barefoot Dancer** — តួនឹងផ្លាស់ទៅកាយវិការថ្មី។

ជំហានទី ៥ — ពន្លឺ និងកាមេរ៉ា
------------------------------

បើក Activity **Lights & Cameras**។

ពន្លឺ
~~~~~~

#. ចុច tab **Lights** នៅខាងឆ្វេង រួចចុច **Presets**។
#. ពង្រីក category **Lights** រួចជ្រើស subcategory **Other**។
#. ចុចពីរដងលើ **LIGHTS - Barefoot Dancer** ដើម្បីផ្ទុក Light Preset។

កាមេរ៉ា
~~~~~~~~

#. ចុច tab **Cameras** (ផ្ទាំងជាប់គ្នានឹង Lights) រួចចុច **Presets**។
#. ជ្រើស category **Barefoot Dancer** នៅជួរខាងឆ្វេង — មានរូបភាពតំណាង Camera Preset ពីរ។
#. ចុចពីរដងលើ **CAMERA 1 - Barefoot Dancer**។ ទិដ្ឋភាពរបស់អ្នកនឹងប្ដូរភ្លាម — អ្នកកំពុងមើលតាមរយៈកាមេរ៉ាដែលទើបផ្ទុក។

ជំហានទី ៦ — ផ្ទៃខាងក្រោយ (Backdrop)
--------------------------------------

ឆាកអាចនៅសល់ចន្លោះទទេនៅផ្ទៃខាងក្រោយ (អ្នកអាចឃើញពណ៌ខៀវនៅជ្រុងខាងឆ្វេងលើ)។ Backdrop Image នឹងបំពេញចន្លោះទាំងនោះ៖

#. ចូល **Edit > Backdrop…** ដើម្បីបើកផ្ទាំងសន្ទនា «Backdrop Options»។
#. ចុចប៊ូតុងក្បែរស្លាក **Image:** រួចជ្រើស **Browse…**។
#. រុករកទៅកន្លែងដំឡើងផលិតផល Genesis 2 Female Starter Essentials — តាមលំនាំដើម៖

   - Windows: ``C:/Users/Public/Documents/My DAZ 3D Library``
   - Mac: ``/Users/Public/Documents/My DAZ 3D Library``

#. បើកថត ``Runtime`` → ``Textures`` → ``DAZ`` → ``Backdrops`` រួចចុចពីរដងលើឯកសារ **dusk sky**។
#. ចុច **Accept** ដើម្បីបិទផ្ទាំងសន្ទនា និងផ្ទុករូបភាពផ្ទៃខាងក្រោយ។

ជំហានទី ៧ — Render ឆាក
--------------------------

#. បើក Activity **Render** ដោយចុចលើ Render activity tab។
#. បើកផ្ទាំង **Content Library** នៅខាងស្ដាំ (មាតិកាទាំងអស់ក្នុង Smart Content ក៏អាចផ្ទុកពីទីនេះបានដែរ)។
#. ក្នុង Container View នៅផ្នែកខាងលើ រុកទៅ **DAZ Studio Formats > My DAZ 3D Library > DAZ Studio Tutorials > Genesis 2 Barefoot Dancer**។
#. អ្នកនឹងឃើញរូបភាពតំណាង Render Settings បី — ចុចពីរដងលើ **Render Settings Low - barefoot Dancer** សម្រាប់ការ Render លឿន (Medium ឬ High ក៏បាន ប៉ុន្តែចំណាយពេលយូរជាង)។
#. បើកផ្ទាំង **Render Settings** (tab នៅខាងឆ្វេង) រួចចុច **General** — Preset ដែលទើបផ្ទុកបានកំណត់ទំហំរូបភាព **700 x 910 ភីកសែល**។ អ្នកអាចប្ដូរទំហំតាមប្រអប់ **Dimensions**។
#. ចុចប៊ូតុង **Render** ពណ៌បៃតងនៅជ្រុងខាងលើស្ដាំនៃផ្ទាំង Render Settings ដើម្បីចាប់ផ្តើម (ឬប្រើផ្លូវកាត់ :kbd:`Ctrl` + :kbd:`R` / :kbd:`Cmd` + :kbd:`R`)។

.. note::

   ការ Render ជាដំណើរការដែលចំណាយពេល — អាស្រ័យលើល្បឿនម៉ាស៊ីន និងការកំណត់ វាអាចចំណាយពេលរហូតដល់មួយម៉ោង ឬច្រើនជាង។ អ្នកអាចតាមដានវឌ្ឍនភាពក្នុង **Render Window**។

ជំហានទី ៨ — រក្សាទុកលទ្ធផល
-----------------------------

#. ពេល Render រួច សរសេរឈ្មោះក្នុងប្រអប់ **Name** រួចចុច **Save** — រូបភាពនឹងត្រូវរក្សាទុកក្នុង Render Library របស់អ្នក។
#. បើកផ្ទាំង **Render Library** (tab នៅខាងឆ្វេង ក្នុង Render activity) រួចចុចពីរដងលើរូបភាពតំណាងរបស់ Render ដើម្បីបើកមើលក្នុងកម្មវិធីលំនាំដើមសម្រាប់ឯកសារប្រភេទនោះ។
#. បើអ្នកកែរូបភាព សូមរក្សាទុកឡើងវិញ។ Render Library ស្ថិតនៅ ``/Users/[ឈ្មោះអ្នកប្រើ]/Documents/DAZ 3D/Studio/Render Library``។

ជាការស្រេច! អ្នកអាចចែករំលែករូបភាព Render របស់អ្នកទៅកាន់បណ្ដាញសង្គម ឬផ្ញើទៅមិត្តភ័ក្ដិបានហើយ។ សម្រាប់ជំហានបន្ទាប់ សូមសិក្សា :doc:`ជំពូកទី ១ — ស្វែងយល់ពីចំណុចប្រទាក់ <chapters/navigating>`។
