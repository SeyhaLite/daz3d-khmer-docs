អ្វីដែលយើង «ឃើញ» គឺពន្លឺដែលចំណាំងផ្លាតពីផ្ទៃវត្ថុ — ពន្លឺផ្ដល់ជីវិតដល់ពិភពជុំវិញខ្លួន ហើយដូចគ្នាដែរ **ពន្លឺក្នុងឆាក 3D ផ្ដល់ជីវិតដល់ឆាក**។ មិនថាអ្នកចង់បានរូបភាពកក់ក្ដៅ និងរស់រវើក ឬត្រជាក់ និងងងឹត — ការបំភ្លឺជួយ **ប្រាប់រឿង** របស់អ្នកបានដូចតួអង្គដែរ។ មនុស្សមានវិចារណញាណខ្លាំង — សូម្បីអ្នកមិនមែនជាសិល្បករក៏អាចមើលឃើញការបំភ្លឺអាក្រក់ក្នុង render។

.. note:: ជំពូកនេះបន្តប្រើ Activity **'Lights & Cameras'** នៃ layout Hollywood Blvd។

Headlamp Lighting (ពន្លឺលំនាំដើម)
-----------------------------------

ហេតុអ្វី render មុនៗមានពន្លឺ ទោះមិនទាន់ដាក់ពន្លឺ? ព្រោះ Daz Studio ប្រើ **«Headlamp»** — ស្រមៃថាទិដ្ឋភាពរបស់អ្នកមានភ្លើងក្បាលបំភ្លឺ៖ អ្វីៗដែលអ្នកមើលត្រូវបានបំភ្លឺល្អឥតខ្ចោះ។ វាល្អសម្រាប់មើលជាមុន និងរៀបចំឆាក ប៉ុន្តែ **មិន realistic** — final render ត្រូវការពន្លឺពិតប្រាកដ។

- ពេលផ្ទុកពន្លឺចូលឆាក Daz Studio **បិទ headlamp** ដោយស្វ័យប្រវត្តិ — ការបំភ្លឺក្នុង Viewport កំណត់ដោយពន្លឺក្នុងឆាក
- ចំនួនពន្លឺដែលមើលជាមុនបានក្នុង Viewport អាស្រ័យលើកាតវីដេអូ — ភាគច្រើនគាំទ្រដល់ **៨ ពន្លឺ**
- ចង់ត្រឡប់ទៅ headlamp វិញ (ឧ. ដើម្បីផ្លាស់ទីតួក្នុងតំបន់ងងឹត)? ប្រើ action **'Use Scene Lights'** ក្នុង toolbar — រូបភាពតំណាងលេចពណ៌ = ប្រើពន្លឺឆាក · មិនលេចពណ៌ = headlamp

បង្កើតពន្លឺថ្មី
---------------

ពន្លឺថ្មីបង្កើតបានពីម៉ឺនុយ **Create** — ពន្លឺប្រភេទនីមួយៗមាន action ផ្ទាល់ខ្លួន (ឧ. **Create > New Distant Light…**)។

ផ្ទាំងសន្ទនា **«Create New Light»** ដូចគ្នានឹង «Create New Camera» (:doc:`ជំពូក ៦ <cameras>`) ទាំងស្រុង៖

- ដាក់ឈ្មោះពន្លឺ — ទម្លាប់ល្អគឺដាក់ឈ្មោះ **តាមមុខងារ** (Key Light, Rim Light, Flood Light, Fill Light...) ដើម្បីស្គាល់វារហ័សក្នុងផ្ទាំង Scene
- **'Show Options »'** → ជ្រើសទីតាំងផ្ទុក៖ ទីតាំងលំនាំដើម ឬ **'Active Viewport Transforms'** (ទីតាំង និងមុំដូចទិដ្ឋភាពសកម្ម)
- ចុច **'Accept'** → ពន្លឺផ្ទុកចូលឆាក ហើយអ្នកនឹងឃើញការបំភ្លឺប្ដូរភ្លាម (headlamp បិទ)។ ពន្លឺជាវត្ថុធម្មតា — ជ្រើស ផ្លាស់ទី បង្វិល បានដូចវត្ថុផ្សេងៗ។

ប្រភេទពន្លឺទាំង ៤
------------------

.. list-table::
   :header-rows: 1
   :widths: 20 40 40

   * - ប្រភេទ
     - លក្ខណៈ
     - ការប្រើប្រាស់ធម្មតា
   * - **Distant Light**
     - ប្រភពពន្លឺពីចម្ងាយគ្មានទីបញ្ចប់ («Infinite Light») — **translation គ្មានន័យ** មានតែ **rotation** ដែលកំណត់ទិសពន្លឺ (ព្រួញនៃ «Distant Light Avatar» បង្ហាញទិស)
     - បំភ្លឺផ្នែកធំនៃឆាក · ក្លែង **ពន្លឺព្រះអាទិត្យ**
   * - **Spotlight**
     - បញ្ចេញពន្លឺជា **រាងកោណ** — ទាំង translation និង rotation កំណត់ទីតាំងភ្លឺ
     - ភ្លើងមុខឡាន ចង្កៀង open-face ភ្លើងពិល និង spotlight ថតរូប
   * - **Point Light**
     - ចំណុចតែមួយក្នុងលំហ បញ្ចេញពន្លឺ **គ្រប់ទិស** — rotation គ្មានឥទ្ធិពល មានតែ **translation**។ អាំងតង់ស៊ីតេទាប — ពិបាកបំភ្លឺឆាកទាំងមូលដោយខ្លួនឯង
     - ទៀន អំពូល ចង្កៀងជញ្ជាំង (chandeliers) · ល្អបំផុតជា **accent** លើពន្លឺដែលមាន
   * - **Linear Point Light**
     - ដូច point light ប៉ុន្តែ **មិន** ដើរតាមច្បាប់រូបវិទ្យា (អាំងតង់ស៊ីតេចុះតាមការេចម្ងាយ) — អ្នកកំណត់ **ចំណុច fall-off** ផ្ទាល់ខ្លួន ទទួលបានឥទ្ធិពល point light ក្នុងអាំងតង់ស៊ីតេខ្ពស់ជាងច្រើន
     - ពេលត្រូវការពន្លឺចំណុចខ្លាំង ដែលគ្រប់គ្រងដែនបាន

ផ្ទាំង Lights
--------------

កន្លែងបត់បែនពន្លឺនីមួយៗ (ពណ៌ អាំងតង់ស៊ីតេ ទីតាំង...) និងផ្ទុក Light(s) Presets។ ស្ថិតនៅខាងឆ្វេង (Activity 'Lights & Cameras') — រៀបចំដូចផ្ទាំង Cameras/Posing/Surfaces៖ ២ pages (**Editor** និង **Presets**)។

~~~~~~~~~~~

- **Property View** (ស្ដាំ) — លក្ខណៈសម្បត្តិនៃ group ដែលជ្រើស

លក្ខណៈសម្បត្តិសំខាន់ៗ
~~~~~~~~~~~~~~~~~~~~~~

**Shadow Type** (ក្នុង group Shadow) — តាមលំនាំដើមពន្លឺ **គ្មានស្រមោល** ('None')។ ដើម្បីឱ្យពន្លឺមើលទៅធម្មជាតិ វាគួរបង្កើតស្រមោល។ ជម្រើសពីរ៖

- **Deep Shadow Map** — render engine គណនាស្រមោលតាមរូបភាព («Shadow Map»)។ **លឿនជាង** និងល្អសម្រាប់ស្រមោលព្រិល/ទន់។ ចំណុចខ្សោយ៖ **«Shadow Bias»** (ទីតាំងស្រមោលធៀបនឹងវត្ថុ) ជារឿយៗមានបញ្ហា
- **Raytraced (Software Only)** — គណនាដោយបាញ់កាំរស្មីពីប្រភពពន្លឺ។ Shadow bias តិចជាង · ស្រមោល **ត្រឹមត្រូវជាង** ទាំងទីតាំង និងទំហំ (កំណត់ដោយទំហំវត្ថុ និងចម្ងាយទៅពន្លឺ)។ យូរជាង និងអាច **គ្រាប់ៗ (grainy)** បើ 'Shadow Softness' ខ្ពស់ពេក — ដោះស្រាយដោយបង្កើន **'Shadow Samples'**។ បើម៉ាស៊ីនអ្នកខ្លាំង នេះជាជម្រើសល្អបំផុត

.. note:: ស្រមោលត្រូវការអ្វីមួយដើម្បីធ្លាក់លើ — ប្រាកដថាឆាកមាន ground plane ឬ geometry ផ្សេងទៀត!

**Shadow Softness** — ស្រមោលរឹង (គែមច្បាស់) ឬទន់ (គែមព្រិល)។ តម្លៃខ្ពស់ = ស្រមោលទន់ជាង។ កែដោយ slider ឬវាយតម្លៃលេខ។

**Illumination** (ក្នុង group Light) — លំនាំដើម = **On**។ ជម្រើសផ្សេង៖ **'Diffuse Only'** (ប៉ះពាល់តែ diffuse channel) · **'Specular Only'** (តែ specular channel) · **'Off'** (បិទវិភាគទានពន្លឺទាំងអស់)។ ក៏អាចបិទតាមរយៈ **រូបភ្នែក** នៅខាងឆ្វេងពន្លឺក្នុងផ្ទាំង Scene បានដែរ។

**Color** — ពណ៌នៃពន្លឺ។ Effect អស្ចារ្យអាចកើតពីការប្ដូរពណ៌៖ render «ត្រជាក់» បានប្រយោជន៍ពីពន្លឺខៀវ/បៃតង · render «កក់ក្ដៅ» ប្រើលឿង ក្រហម ឬទឹកក្រូច។ ចុចលើ color widget → ផ្ទាំងសន្ទនា «Select Color» · ឬដាក់ទ្រនិចលើតម្លៃ RGB (ទ្រនិចប្រែជាព្រួញទ្វេ) រួចអូស។

**Intensity** — ភាពភ្លឺនៃពន្លឺ (តម្លៃណែនាំសម្រាប់ពន្លឺនីមួយៗមើលក្នុងផ្នែក 3-point lighting ខាងក្រោម)។ កែដោយ slider ឬតម្លៃលេខ។

**Spread Angle** — *(សម្រាប់តែ Spotlight)* — ទទឹងនៃកោណពន្លឺ។ បង្កើន = ផ្ទៃភ្លឺធំជាង · បន្ថយ = ពន្លឺប្រមូលតូច។

**Falloff Start / Falloff End** — *(សម្រាប់តែ Linear Point Light)* — ពេលផ្ទុក អ្នកនឹងឃើញ **បាល់ពីរ**៖ បាល់ខាងក្នុង = Falloff Start · បាល់ខាងក្រៅ = Falloff End។

- ក្នុងបាល់ខាងក្នុង → ភ្លឺ **ពេញអាំងតង់ស៊ីតេ**
- ចន្លោះបាល់ទាំងពីរ → ពន្លឺចាប់ផ្តើម «fall off» (ថយចុះបន្តិចម្ដងៗ)
- ក្រៅបាល់ខាងក្រៅ → អាំងតង់ស៊ីតេ 0 (មិនភ្លឺ)

Light(s) Preset ផ្ទុកពន្លឺមួយ ឬមួយឈុតចូលឆាក — អាចរចនាសម្រាប់ឆាកជាក់លាក់ ឬប្រើទូទៅ។ វាជាវិធីដ៏ល្អដើម្បីទទួលបានការបំភ្លឺគុណភាពខ្ពស់ភ្លាមៗ។ Page នេះដំណើរការដូច Smart Content (categories ខាងឆ្វេង · ឯកសារខាងស្ដាំ)។

- ផ្ទុកដោយចុចពីរដង ឬអូសទម្លាក់ · ក៏អាចផ្ទុកពី Smart Content ឬ Content Library បានដែរ
- ⚠️ ការផ្ទុកធម្មតា **ជំនួសពន្លឺទាំងអស់** ក្នុងឆាក!
- សង្កត់ :kbd:`Ctrl` (PC) / :kbd:`Cmd` (Mac) ពេលផ្ទុក → ផ្ទាំងសន្ទនា **«Light Preset Load Options»** — ជម្រើស **'Action'**៖ ជំនួសទាំងអស់ · ជំនួសតែពន្លឺដែលជ្រើស · ឬ **បន្ថែម** (មិនជំនួស)
- Daz Studio ភ្ជាប់ Light(s) Presets សម្រាប់ឆាក **'Alchemy Chasm'** + presets ទូទៅមួយចំនួន · បន្ថែមអាចទិញពី DAZ 3D Store

មើលតាមរយៈពន្លឺ
------------------

Distant lights និង spotlights (មិនមែន point lights) អាចធ្វើជា **ទិដ្ឋភាពសកម្ម** របស់ Viewport បាន៖

#. បើក View Selection Menu — ក្រោមបញ្ជីកាមេរ៉ា អ្នកនឹងឃើញ distant lights និង spotlights ទាំងអស់ក្នុងឆាក
#. ជ្រើសមួយ → អ្នកមើលឆាក **ពីទស្សនៈរបស់ពន្លឺ**

- មើលតាម **distant light** = គ្មាន perspective (ដូច orthographic views)
- មើលតាម **spotlight** = មាន perspective — **Spread Angle** របស់វាកំណត់ field of view
- ប្រើ orbit, pan, frame និង camera cube ដើម្បីតម្រង់ពន្លឺដោយ **ជាក់លាក់** — ឃើញច្បាស់ពីចំណុចដែលពន្លឺបំភ្លឺ។ នេះអនុញ្ញាតការកែលម្អិតដ៏សំខាន់ដែលពិបាកធ្វើតាមវិធីផ្សេង។

បច្ចេកទេស៖ 3-Point Lighting Rig
----------------------------------

ការបំភ្លឺ ៣ ចំណុចជារៀបចំដ៏ពេញនិយម ទាំងក្នុងពិភព 3D និងការថតរូបពិត — ពន្លឺ ៣ បំភ្លឺប្រធានបទតែមួយសម្រាប់រូបភាព portrait។ ក្នុង Daz Studio អាចប្រើ spotlights ឬ distant lights សម្រាប់ចំណុចទាំង ៣ (distant សាមញ្ញជាង · spot ផ្ដល់ការគ្រប់គ្រងលើស្រមោល និងការបំភ្លឺច្រើនជាង)។

.. list-table::
   :header-rows: 1
   :widths: 16 44 20 20

   * - ពន្លឺ
     - តួនាទី និងទីតាំង
     - ទីតាំងណែនាំ
     - អាំងតង់ស៊ីតេចាប់ផ្តើម
   * - **Key Light**
     - ពន្លឺមេ — បំភ្លឺមុខ និងផ្នែកខាងមុខនៃប្រធានបទ។ ដាក់នៅខាងមុខ បញ្ចាំងមកប្រធានបទ។ ភាគច្រើនដាក់ខុសបន្ដិច (offset) ពីបន្ទាត់កណ្ដាល ជាជាងត្រង់ៗ — ហើយជាទូទៅនៅ **ខាងលើ** បញ្ចាំងចុះក្រោម (ព្រោះមនុស្សធ្លាប់នឹងពន្លឺមកពីលើ)។ កំណត់អាំងតង់ស៊ីតេឱ្យប្រធានបទច្បាស់ ប៉ុន្តែមិន «washed out»
     - ឆ្វេង ឬស្ដាំ ០–៤៥° ពីបន្ទាត់កណ្ដាល (ដែន ៩០°)
     - **100%**
   * - **Fill Light**
     - បំពេញកន្លែងងងឹតដែល Key Light ទុកចោល — ក៏នៅខាងមុខប្រធានបទដែរ ប៉ុន្តែ offset ពី Key ប្រហែល **៩០°** (ឧ. Key នៅ ១៥° ឆ្វេង → Fill នៅ ~៧៥° ស្ដាំ)។ មិនត្រូវខ្លាំងជាង Key ទេ — គ្រាន់តែបំពេញចន្លោះងងឹតនៅផ្នែកខាងមុខ និងចំហៀង
     - ម្ខាងទៀតនៃ Key ~៩០°
     - **~40%** (ថយចុះបើភ្លឺពេក)
   * - **Rim Light**
     - ពន្លឺពី **ខាងក្រោយ** ប្រធានបទ — ពេលដាក់ត្រូវ វាចាប់ **គែម** របស់ប្រធានបទឱ្យលេចធ្លោ និងបំភ្លឺផ្នែកសល់នៃឆាក (បញ្ចាំងទៅទិសកាមេរ៉ាជាទូទៅ)។ Offset វាទៅរក Fill ដើម្បីកុំឱ្យរួមជាមួយ Key ធ្វើឱ្យប្រធានបទ washed out។ Daz Studio អនុញ្ញាត **overdrive** (អាំងតង់ស៊ីតេលើស 100%)
     - ខាងក្រោយប្រធានបទ offset ទៅរក Fill
     - **~120%** (ភ្លឺបំផុតក្នុងឆាក)

.. note:: គ្មានច្បាប់ចាប់បង្ខំទេ — មានតែ **គោលការណ៍ណែនាំ**។ គោលដៅចុងក្រោយ៖ បំភ្លឺប្រធានបទ និងធ្វើឱ្យវា **លេចធ្លោ**។

ត្រួតពិនិត្យដោយ Spot Render
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

ពន្លឺនីមួយៗធ្វើអន្តរកម្មជាមួយពន្លឺផ្សេងៗ និងផ្ទៃរបស់តួ តាមរបៀបដែល preview មិនអាចបង្ហាញត្រឹមត្រូវបាន — ដើម្បីឃើញច្បាស់ ត្រូវ **Render**។ ប្រើ **Spot Render Tool** (មើល :doc:`ជំពូក ៣ <textures>`)៖ បើកឧបករណ៍ក្នុង toolbar រួចចុច + អូសលើផ្ទៃដែលចង់ត្រួតពិនិត្យ — Daz Studio នឹង Render តែតំបន់នោះក្នុង Viewport ដោយប្រើការកំណត់បច្ចុប្បន្ន។

ចងចាំ៖ ការប្ដូរទីតាំង អាំងតង់ស៊ីតេ ឬពណ៌នៃពន្លឺមួយ **ប៉ះពាល់ដល់រូបរាងពន្លឺផ្សេងទៀតទាំងអស់**។

រក្សាទុក Light(s) Preset ផ្ទាល់ខ្លួន
--------------------------------------

#. ជ្រើសពន្លឺក្នុងផ្ទាំង Scene (បើចង់រក្សាតែពន្លឺមួយ) — បើចង់រក្សាទាំងអស់ ការជ្រើសមិនសំខាន់ទេ
#. **File > Save As > Light(s) Preset…** → ផ្ទាំងសន្ទនា «Filtered Save» — ដាក់ឈ្មោះ ជ្រើសទីតាំង ចុច **Save**
#. ផ្ទាំងសន្ទនា **«Light(s) Preset Save Options»** — ៣ ផ្នែក៖

   - **Animation Range** — 'Current Frame Only' ឬ 'Animated Range' (Start/End Frame)
   - **Light Data** — 'Selected Light(s)' ឬ **'All Lights'**
   - **File Options** — compress ឬទេ

#. ចុច **Accept** — preset លេចក្រោម category **'Uncategorized'** នៃ Presets page (ផ្ទាំង Lights)។ ចុចពីរដង ឬអូសទម្លាក់ដើម្បីផ្ទុកវិញ។

.. tip:: ការបំភ្លឺល្អត្រូវការ **ការអនុវត្ត និងអំណត់** — គ្មានប៊ូតុង «Make Art» ទេ។ ប៉ុន្តែដំណើរការនេះផ្ដល់រង្វាន់ — សិល្បករម្នាក់ៗមានលក្ខណៈពិសេស ហើយអ្នកអាចប្រើការបំភ្លឺដើម្បីបង្ហាញខ្លួនឯង។
