**Rendering** គឺដំណើរការបំលែងឆាក 3D របស់អ្នកទៅជារូបភាព ២ វិមាត្រ ឬ animation — ជាជំហានចុងក្រោយនៃលំហូរការងារ និងជាពេលដែលអ្នក «ប្រមូលផល» នៃការងារទាំងអស់។

ពេល Render កម្មវិធីគណនាតម្លៃ RGB សម្រាប់ pixel នីមួយៗ ដោយផ្អែកលើពន្លឺ ផ្ទៃ poses shaping ជាដើម។ ប៉ុន្តែការ Render មិនមែនគ្រាន់តែចុចប៊ូតុងទេ — **ការកំណត់ Render (Render Settings)** កំណត់គុណភាព និងរូបរាងទាំងមូលនៃរូបភាព។ តួអង្គអស្ចារ្យ + pose ស្អាត + ពន្លឺល្អ ក៏អាចចេញជារូបភាពគុណភាពទាបបាន បើការកំណត់មិនត្រឹមត្រូវ។

.. note:: ជំពូកនេះប្រើ Activity **'Render'** នៃ layout Hollywood Blvd។

ផ្ទាំង Render Settings
----------------------

កន្លែងមើល និងបត់បែនការកំណត់ Render ទាំងអស់ — ស្ថិតនៅខាងឆ្វេងនៃចំណុចប្រទាក់។ មាន ២ pages៖

- **General** — ការកំណត់មូលដ្ឋាន (Quality, Render Style, Dimensions)
- **Advanced** — រួមការកំណត់ទាំងអស់របស់ General + ការកំណត់កម្រិតខ្ពស់បន្ថែម

Render Quality
~~~~~~~~~~~~~~

ការកំណត់ដែលមានទីតាំងលេចធ្លោនៅផ្នែកខាងលើផ្ទាំង។ គោលការណ៍សាមញ្ញ៖ **គុណភាពខ្ពស់ = Render យូរ** (អាច «លះបង់» គុណភាពដើម្បីល្បឿន)។

.. list-table::
   :header-rows: 1
   :widths: 12 88

   * - កម្រិត
     - លក្ខណៈ
   * - **4** (ខ្ពស់បំផុត)
     - ប្រើ **software render engine** — ឃើញឥទ្ធិពលពេញលេញនៃផ្ទៃ ពន្លឺ និងស្រមោល។ ការគណនាធ្វើដោយ CPU ដូច្នេះល្បឿន processor កំណត់រយៈពេល។ **ប្រើសម្រាប់ final render ជានិច្ច**
   * - **1–3**
     - ការគណនាដោយ **កាតក្រាហ្វិក** — ល្បឿន និងគុណភាពអាស្រ័យលើកាត។ ជម្រើសល្អសម្រាប់ preview ប៉ុន្តែ software render តែងតែមានគុណភាពខ្ពស់ជាង មិនថាកាតល្អប៉ុណ្ណាទេ
   * - **0** (ទាបបំផុត)
     - គ្រាន់តែជា **OpenGL preview** — ដូចថតរូបភាពអ្វីដែលអ្នកឃើញក្នុង Viewport។ ពន្លឺគុណភាពទាបបំផុត **គ្មានស្រមោល** — ប៉ុន្តែលឿនស្ទើរភ្លាមៗ

Render Style
~~~~~~~~~~~~

- **Default** — Render ដោយប្រើការកំណត់សម្ភារៈដែលមានក្នុងឆាកដូចដែលវាមាន
- **Cartoon** — Daz Studio អនុវត្ត toon version នៃ default surface shader ទៅផ្ទៃទាំងអស់ដែលប្រើ «DAZ Studio Default» shader (ការកំណត់ទាំងអស់ត្រូវបានផ្ទេរទៅ toon shader)

.. tip:: Shader ទាំងពីរល្អដូចគ្នា — សាក Render ឆាកតែមួយជាមួយ style ទាំងពីរដើម្បីឃើញភាពខុសគ្នា!

Dimensions (ទំហំ និងសមាមាត្រ)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

កំណត់ទំហំ («Size» = ចំនួន **Pixels**) និងសមាមាត្រ («Aspect Ratio» = **Aspect**) នៃរូបភាព៖

- **Preset** — ម៉ឺនុយធ្លាក់ចុះជាមួយសមាមាត្រស្រាប់ពីឧស្សាហកម្មភាពយន្ត/ថតរូប៖ 4:3, 16:9, Super 8mm និងផ្សេងៗទៀត។ បង្កើតសមាមាត្រផ្ទាល់ខ្លួន? ចុច **'Save Preset…'** ដើម្បីរក្សាទុក (វានឹងលេចក្នុងបញ្ជី Preset)
- **Pixels** — ប្រអប់ទី ១ = កម្ពស់ · ទី ២ = ទទឹង។ បើ **'Constrain Proportions'** ធីក ការកែប្រអប់មួយនឹងកែប្រអប់មួយទៀតដោយស្វ័យប្រវត្តិ។ ⚠️ Pixels កាន់តែច្រើន = Render កាន់តែយូរ
- **Aspect** — កម្ពស់/ទទឹងធៀប (វាយលេខផ្ទាល់ខ្លួនបាន)។ ការប្ដូរ Aspect នឹង update «Aspect Frame» ក្នុង Viewport (បើបើក)

.. note:: តាមលំនាំដើម **Aspect Frame បិទ**។ បើកវាដើម្បីឃើញច្បាស់ថាផ្ទៃណានៃឆាកនឹងត្រូវ Render៖ Viewport Options Menu → **'Show Aspect Frame'** (លើកលែងពេល Aspect = 'Active Viewport')។

ការកំណត់កម្រិតខ្ពស់ (Page Advanced)
------------------------------------

ការកំណត់ខាងក្រោមលេចឡើងក្នុង page **Advanced** ពេល Render Quality = **4**។ ក្នុងចំណោមការកំណត់ជាច្រើន នេះជា ៣ សំខាន់បំផុតសម្រាប់គុណភាព៖

**Max Ray Trace Depth** — ចំនួនដងដែលកាំរស្មីពន្លឺ «លោត» (bounces) ក្នុងការគណនាមួយ។ លំនាំដើម = **2** ដែលគ្រប់គ្រាន់សម្រាប់ render ភាគច្រើន។ បង្កើនតែពេលឆាកមាន **ផ្ទៃចំណាំងផ្លាតច្រើន** — ការបង្កើនអាចធ្វើឱ្យរយៈពេល Render កើនឡើងយ៉ាងខ្លាំង!

**Shadow Samples** — ចំនួន samples ដែល render engine ប្រើដើម្បីបង្កើតស្រមោល។ Samples ច្រើន = ស្រមោលគុណភាពខ្ពស់ + ពេលយូរ · samples តិច = លឿន ប៉ុន្តែស្រមោលអាចគ្រាប់ៗ (grainy)។ លំនាំដើម = **16** — កែតាមចំនួនពន្លឺ តួនាទីរបស់ស្រមោលក្នុងឆាក និង Shadow Softness។

**Shading Rate** — កម្រិតព័ត៌មានលម្អិតនៃ render។ Rate **ខ្ពស់** = Render លឿន ប៉ុន្តែបាត់បង់ព័ត៌មានលម្អិត · Rate **ទាប** = ព័ត៌មានលម្អិតច្រើនបំផុត។ លំនាំដើម = **1.00** (គោលល្អសម្រាប់ render ភាគច្រើន)។

- Portrait ជិតមុខ (close-up)? → ដាក់ rate **ទាប** ដើម្បីចាប់ព័ត៌មានលម្អិតអតិបរមា
- ប្រធានបទនៅឆ្ងាយ? → ដាក់ rate **ខ្ពស់** បាន (ព័ត៌មានលម្អិតតូចៗមិនឃើញទេ)
- Render យូរពេក? → ដំឡើង rate · ត្រូវការព័ត៌មានលម្អិតបន្ថែម? → បន្ថយ rate

Render Settings Presets
-----------------------

Presets អនុញ្ញាតឱ្យរក្សាទុក/ផ្ទុកការកំណត់ Render — preset រួមព័ត៌មាន **គ្រប់ការកំណត់** ទាំង page General និង Advanced។

.. warning:: ពេលផ្ទុក Render Settings Preset វានឹង **ជំនួសការកំណត់ទាំងអស់** របស់អ្នក។

- **រក្សាទុក៖** កំណត់ការកំណត់ឱ្យដូចចិត្តសិន → **File > Save As > Render Settings Preset…** → ផ្ទាំងសន្ទនា «Filtered Save» (ដាក់ឈ្មោះ + ទីតាំង) → **Save**
- **ផ្ទុក៖** ពីផ្ទាំង **Content Library** ឬ **Smart Content** — រុករករហូតដល់ឃើញ preset រួចចុចពីរដង។ Preset ដែលទើបរក្សាទុកស្ថិតក្រោម category **'Uncategorized'** ក្នុង Smart Content

ចាប់ផ្តើម Final Render
----------------------

ឆាករៀបចំរួចរាល់ ពន្លឺត្រឹមត្រូវ សម្ភារៈស្អាត សមាសភាព និង framing ល្អឥតខ្ចោះ — ដល់ពេល Render!

.. important::

   Rendering ជាដំណើរការដែលប្រើធនធានខ្លាំង — អាចចំណាយពីវិនាទី ដល់ នាទី ម៉ោង ឬសូម្បីតែ **ថ្ងៃ** (អាស្រ័យលើម៉ាស៊ីន និងភាពស្មុគស្មាញនៃឆាក)។ **រក្សាទុកឆាកមុនពេល Render ជានិច្ច** (**File > Save**) — បើមានអ្វីខុសប្រក្រតី អ្នកមិនបាត់បង់ការងារទេ។

វិធីចាប់ផ្តើម Render (ជ្រើសមួយ)៖

- ចុចប៊ូតុង **'Render'** នៅផ្នែកខាងលើនៃផ្ទាំង Render Settings
- ចុចប៊ូតុង **'Render'** ក្នុង toolbar
- ម៉ឺនុយ **Render > Render** នៅ Main Menu Bar
- ផ្លូវកាត់ :kbd:`Ctrl` + :kbd:`R` (PC) / :kbd:`Cmd` + :kbd:`R` (Mac)

តាមលំនាំដើម Render បើក **បង្អួចថ្មី** («Render Window») — ពេលកំពុង Render អ្នកមិនអាចធ្វើអ្វីផ្សេងក្នុង Daz Studio បានទេ។ តាមដានវឌ្ឍនភាពក្នុង Render Window · ចុច **'Cancel'** (ជ្រុងខាងក្រោមស្ដាំ) ដើម្បីបញ្ឈប់ · ពេលចប់ ប៊ូតុង Cancel ប្រែទៅជា **'Close'**។

រក្សាទុកលទ្ធផល Render
----------------------

Render ចប់ហើយនៅតែត្រូវរក្សាទុក! (បើមិនពេញចិត្ត ចុច 'Close' ដើម្បោះបោះចោលបាន)

#. ដាក់ឈ្មោះក្នុងប្រអប់ **'Name'**
#. ជ្រើសទម្រង់ឯកសារពីម៉ឺនុយធ្លាក់ចុះ៖ ``.jpg``, ``.png``, ``.tiff`` ឬ ``.bmp`` សម្រាប់រូបភាពនៅនឹងថ្កល់
#. ជ្រើសទីតាំងរក្សាទុក៖

   - លំនាំដើម = **«Render Library»** របស់ Daz Studio (មើលបានពីផ្ទាំង Render Library · ប្រើគ្រាប់ **+** ដើម្បីបង្កើតថតក្នុង library)
   - ទីតាំងផ្សេង = ជ្រើស **'Folder'** ពីម៉ឺនុយធ្លាក់ចុះខាងឆ្វេង រួចចុចប៊ូតុង **'…'** ខាងស្ដាំដើម្បីរុករក

#. ចុច **'Save'** — Daz Studio រក្សាទុករូបភាព ២ វិមាត្រនៅទីតាំងដែលជ្រើស

ឥឡូវអ្នកអាចចែករំលែករូបភាពជាមួយមិត្តភ័ក្ដិ គ្រួសារ ឬសហការី ឬបើកកែក្នុងកម្មវិធីកែរូបភាព ២ វិមាត្រដូចជា Adobe® Photoshop®។
