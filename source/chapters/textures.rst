ក្នុងកម្មវិធី 3D ភាគច្រើន ពេលគំរូត្រូវបានបង្កើត តាមលំនាំដើមវាមានពណ៌តែមួយ — ជាធម្មតាពណ៌ប្រផេះ។ ប្រៀបធៀបនឹងពិភពពិត៖ ចម្លាក់ដីឥដ្ឋមានពណ៌តាមដីឥដ្ឋ រហូតដល់សិល្បករលាបពណ៌ ឬលាបថ្នាំ។ ដូចគ្នានឹង 3D — ជំនួសការលាបពណ៌ផ្ទាល់លើគំរូ Daz Studio ប្រើ **«Textures»** ឬ **«Image Maps»** ដើម្បីផ្ដល់ពណ៌ដល់គំរូ។

.. note:: គំរូភាគច្រើនដែលទិញពី DAZ 3D ផ្ទុកមកជាមួយ texture រួចហើយ — ប៉ុន្តែអ្នកនៅតែអាចបត់បែនផ្ទៃបាន។

លទ្ធភាពគ្មានទីបញ្ចប់៖ អ្នកអាចមុជជ្រៅក្នុង hyper-realism (ផ្ទៃដូចពិតបំផុត) ធ្វើឱ្យ render មានរូបរាងតុក្កតា (stylized/cartoon) ឬអ្វីមួយនៅចន្លោះនោះ។

គោលគំនិតមូលដ្ឋាន
------------------

Surface (ផ្ទៃ)
~~~~~~~~~~~~~~~

«Surface» គឺជាផ្នែករងជាក់លាក់នៃគំរូ 3D — ក្រុម polygon ជាក់លាក់ដែលចែករំលែកលក្ខណៈសម្បត្តិរួមគ្នា សម្រាប់ពណ៌នាពីរូបរាងផ្ទៃរបស់គំរូ។ ពេលសិល្បករ model វត្ថុមួយ គាត់កំណត់ផ្នែកនីមួយៗនៃគំរូទៅ surface ដែលមានឈ្មោះ — ចប់ក្ដី polygon ទាំងអស់ស្ថិតក្រោម surface ណាមួយ។ គំរូសាមញ្ញអាចមាន surface តែមួយ ចំណែកគំរូស្មុគស្មាញមានច្រើន — ឧទាហរណ៍ តួ **Genesis មាន ២៦ surfaces**។

**ឧទាហរណ៍៖** ស្រមៃថាអ្នក model អាវធំមួយ — វាមានកូនប៊ូតុង ខ្សែរូត ប្រាក់ចង និងក្រណាត់។ អ្នក model ឆ្លាតវៃនឹងកំណត់កូនប៊ូតុងទៅ surface របស់វា ខ្សែរូតទៅ surface របស់វា... ដូច្នេះអ្នកប្រើអាចបត់បែនរូបរាងផ្នែកនីមួយៗដាច់ដោយឡែក — ឧ. ធ្វើឱ្យក្រណាត់មានរូបរាង matte ខណៈកូនប៊ូតុង និងប្រាក់ចងរលង។

Image Map (ផែនទីរូបភាព)
~~~~~~~~~~~~~~~~~~~~~~~~

«Image Map» គឺជារូបភាព ២ វិមាត្រដែល «រុំ» (wrap) ជុំវិញ surface។ ការងារផ្ទៃភាគច្រើនធ្វើឡើងដោយ image maps — វាជាវិធីងាយស្រួលបំផុតដើម្បីទទួលបានលទ្ធផលដែលមិនដូចៗគ្នាពេញផ្ទៃ (ឧ. ស្បែកមានហ្វ្រាំង/ស្នាម)។ សរុបមក វាបន្ថែមព័ត៌មានលម្អិតដល់ផ្ទៃគំរូ។

.. note:: Image maps ជួនកាលហៅថា «Texture Maps» — ជាពិសេសពេលប្រើសម្រាប់លក្ខណៈសម្បត្តិ Diffuse Color។

របៀបដែល image map រុំជុំវិញគំរូ កំណត់ដោយ **«UV Set»** — សំណុំកូអរដោនេ ២ វិមាត្រដែលត្រូវនឹងចំណុច ៣ វិមាត្រលើគំរូ។ Genesis និង Genesis 2 មានសមត្ថភាព morph ខ្លាំង ដូច្នេះ Daz Studio អនុញ្ញាត **UV sets ច្រើន** សម្រាប់តួមួយ — អ្នកបង្កើត morph ខ្លាំងអាចភ្ជាប់ UV set បន្ថែមដែលគិតគូរពីការបំភ្លៃដែល morph បង្ក។ UV sets ច្រើនក៏បង្កើនភាពស្របគ្នានៃ texture រវាងតួផ្សេងៗដែរ។

Surface Shader
~~~~~~~~~~~~~~

«Surface Shader» គឺជា **កម្មវិធី** ដែល «Render Engine» ដំណើរការសម្រាប់ចំណុចដែលមើលឃើញនីមួយៗលើផ្ទៃ ដើម្បីកំណត់ពណ៌ និង opacity ចុងក្រោយ — វាគណនាពីរបៀបដែលផ្ទៃប្រតិកម្មនឹងពន្លឺ ចំណាំងផ្លាត ឬចំណាំងបែរ ជាដើម។ ជាចុងក្រោយ វាកំណត់តម្លៃ RGB សម្រាប់ pixel ទាំងអស់ក្នុងឆាក។ អ្នកមិនអាច «ឃើញ» shader ក្នុងឆាកទេ — ឃើញតែលទ្ធផលរបស់វា។

Daz Studio មាន shader ៥ ប្រភេទ៖ **Surface, Light, Volume, Imager និង Displacement** — ក្នុងនោះ custom surface shader ជាប្រភេទធម្មតាបំផុត។ សំណាងល្អ Daz Studio ភ្ជាប់មកជាមួយ shaders រួចរាល់ជាច្រើន ដូច្នេះអ្នកមិនចាំបាច់សរសេរខ្លួនឯងទេ។

.. important::
   - Surface shader ដែលដាក់លើផ្ទៃ **កំណត់លក្ខណៈសម្បត្តិដែលមាន** សម្រាប់ផ្ទៃនោះក្នុងផ្ទាំង Surfaces
   - ពាក្យ «Shader Preset» ≠ shader (ការហៅ Shader Preset ថា shader ជាការយល់ច្រឡំ)
   - ការ Render ដោយ 3Delight នៃផ្ទៃដែលមាន custom shader អាចខុសពីការមើលជាមុនក្នុង Viewport យ៉ាងខ្លាំង

Page Editor
~~~~~~~~~~~

រៀបចំស្រដៀងផ្ទាំង Parameters៖

- **ជួរឆ្វេង** — ការជ្រើសឆាកបច្ចុប្បន្ន + វត្ថុពាក់ព័ន្ធ (សម្លៀកបំពាក់ សក់ props)។ ពង្រីកវត្ថុដើម្បីឃើញ surfaces របស់វា។
- ក្រោមតួមាន **«Surface Selection Sets»** — ក្រុមផ្ទៃកំណត់ជាមុន (ឧ. មុខ + ក្បាល + បបូរមាត់កែព្រមគ្នា) រុករកតាម 'Default Templates' ឬ 'Legacy Surfaces' · និង **«Surfaces»** — ផ្ទៃនីមួយៗសម្រាប់ជ្រើសកែដាច់ដោយឡែក
- ជ្រើសផ្ទៃច្រើន៖ សង្កត់ :kbd:`Ctrl` (PC) / :kbd:`Cmd` (Mac) + ចុចឆ្វេង
- **Filters** — «All» បង្ហាញលក្ខណៈសម្បត្តិទាំងអស់ · «Currently Used» បង្ហាញតែអ្វីដែលកំពុងប្រើ

.. note:: ការជ្រើសត្រូវមាន geometry ទើបលេចក្នុង Surfaces pane — វត្ថុគ្មាន geometry ដូចជា Lights និង Cameras មិនលេចទេ។

- **ជួរស្ដាំ** — លក្ខណៈសម្បត្តិទាំងអស់របស់ផ្ទៃដែលជ្រើស។ Shader បច្ចុប្បន្នបង្ហាញនៅផ្នែកខាងលើផ្ទាំង — ធម្មតាបំផុតគឺ **«DAZ Studio Default»** ប៉ុន្តែអ្នកក៏នឹងឃើញ 'omUberSurface', 'AoA_SubSurface' និង custom shaders ផ្សេងៗ។

Diffuse Color និង Diffuse Strength
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

ក្នុងពិភពពិត ផ្ទៃវត្ថុស្រូបរលកពន្លឺខ្លះ និងចំណាំងផ្លាតរលកផ្សេងទៀត — ពណ៌ដែលយើងឃើញគឺរលកដែលត្រូវបានចំណាំងផ្លាត។ «Diffuse reflection» ជាការចំណាំងផ្លាតខ្ចាត់ខ្ចាយទៅគ្រប់ទិស — **Diffuse Color** គឺពណ៌ [matte] ដែលយើងមើលឃើញនៃផ្ទៃ។

- វិធីទី ១៖ កែតម្លៃ RGB — អូសលេខណាមួយ ឬចុចលើប្រអប់ពណ៌ដើម្បីបើកផ្ទាំងសន្ទនា «Select Color» (ប៉ះពាល់ផ្ទៃទាំងមូលស្មើៗគ្នា)
- វិធីទី ២៖ ផ្ទុក image map — ចុច **«Image Menu Button»** (រូបភាពតំណាងមានព្រួញចុះក្រោម នៅខាងឆ្វេងនៃលក្ខណៈសម្បត្តិ) → ម៉ឺនុយបង្ហាញ textures ដែលប្រើថ្មីៗ + **Browse…** សម្រាប់រុករកថាស។ Image map ផ្ដល់រូបរាងពិតជាង ព្រោះផ្ទៃមិនមានពណ៌តែមួយទេ។

**Diffuse Strength** = ភាគរយពន្លឺដែលផ្ទៃចំណាំងផ្លាត៖ ``0%`` = ស្រូបពន្លឺទាំងអស់ (ផ្ទៃខ្មៅ) · ``100%`` = ពណ៌មានកម្លាំងពេញ។ អាចប្រើ **grayscale image map** បានដែរ — ពណ៌ស = 100%, ខ្មៅ = 0%, ប្រផេះ = កណ្ដាល (ងងឹតជាង = តិចជាង) ដើម្បីប្រែប្រួលតម្លៃពេញផ្ទៃ។ ពេលមាន image map តម្លៃ slider ដើរតួជា **គុណ** (multiplier)។

Specular Color, Specular Strength និង Glossiness
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

ពេលកាំពន្លឺបុកផ្ទៃ ហើយចំណាំងផ្លាតទៅ **ទិសតែមួយ** នោះហៅថា specular reflection។

- **Specular Color** = ពណ៌នៃ highlight ដែលបង្កដោយការចំណាំងផ្លាតផ្ទាល់នេះ (មិនមែនសម្រាប់បង្កើតកញ្ចក់ទេ!)។ កែដូច Diffuse Color — RGB ឬ image map។
- **Specular Strength** = ភាគរយនៃការចំណាំងផ្លាត specular៖ ``0%`` = គ្មាន highlight · ``100%`` = កម្លាំងពេញ។ កែដូច Diffuse Strength (slider ឬ grayscale map — slider ជា multiplier)។
- **Glossiness** = **ទំហំ** នៃ specular highlight៖ ផ្ទៃកាន់តែរលង → highlight កាន់តែតូច និងមុត · glossiness ទាប → highlight ខ្ចាត់ខ្ចាយលើផ្ទៃធំជាង (ហើយមើលទៅ «ខ្សោយ» ជាង ទោះ Specular Strength នៅដដែល)។ ក៏ប្រើ grayscale map បានដែរ។

Ambient Color និង Ambient Strength
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

«Ambient light» = ឥទ្ធិពលស្មើៗគ្នាដែលពន្លឺលោតត្រឡប់ (bounced light) មានលើឆាក — ផ្ទុយពីពន្លឺផ្ទាល់ពីប្រភពជាក់លាក់។ ជំនួសឱ្យពន្លឺតែមួយគ្រប់គ្រងផ្ទៃទាំងអស់ Daz Studio ផ្ដល់ការគ្រប់គ្រងដាច់ដោយឡែក **សម្រាប់ផ្ទៃនីមួយៗ**។ Ambient light ប៉ះពាល់ពណ៌ និងតម្លៃនៃ «core shadows» លើផ្ទៃ។

- **Ambient Color** — លំនាំដើម RGB ``0, 0, 0`` (ខ្មៅ) ដូចពិភពពិត។ ប៉ុន្តែការប្ដូរវាបង្កើត effect គួរឱ្យចាប់អារម្មណ៍ — ដែលពេញនិយមបំផុតគឺធ្វើឱ្យផ្ទៃ «ភ្លឺ» (glow) ក្នុងតំបន់ពន្លឺខ្សោយ។ ផ្ទៃមិនបញ្ចេញពន្លឺពិតទេ ប៉ុន្តែបើ Ambient Color ស្រាលជាងឆាកជុំវិញ វា *មើលទៅ* ដូចជាភ្លឺ។
- **Ambient Strength** — បរិមាណ ambient light ដែលផ្ទៃទទួល។ ឥទ្ធិពលនេះ **មិន** រាលដាលទៅផ្នែកផ្សេងនៃឆាកទេ — ប៉ះពាល់តែផ្ទៃដែលជ្រើស។

Opacity (ភាពថ្លា)
^^^^^^^^^^^^^^^^

- ``100%`` = opaque (មិនថ្លាសោះ) · ``0%`` = ថ្លាទាំងស្រុង · កណ្ដាល = translucent
- **Opacity Map** = grayscale image map ដែលខ្មៅ = ថ្លា 100% · ស = opaque 100% — អនុញ្ញាតឱ្យ «កាត់» ផ្នែកខ្លះនៃផ្ទៃចេញ (ឧ. ធ្វើរន្ធ ឬលំនាំក្រណាត់)

.. note:: Opacity maps ជារឿយៗហៅថា «transparency maps» — តាមពិតពាក្យនេះខុសបច្ចេកទេស (transparency map ពិតប្រាកដគឺច្រាសនៃ opacity map) ប៉ុន្តែគេប្រើជំនួសគ្នា។

Bump (ក្លែងភាពគ្រើម)
^^^^^^^^^^^^^^^^^^^^

ផ្ទៃក្នុងពិភពពិតកម្រល្អឥតខ្ចោះណាស់ — ស្បែកមានរន្ធ ជញ្ជាំងមានវាយនភាព។ **Bump** ក្លែងភាពមិនល្អឥតខ្ចោះទាំងនោះ **ដោយមិនប្ដូរ mesh** របស់វត្ថុ។

- **Bump Map** = grayscale image៖ RGB ``128, 128, 128`` = អព្យាក្រឹត · ស្រាលជាង = bump វិជ្ជមាន (លៀនចេញ) · ងងឹតជាង = bump អវិជ្ជមាន (លិចចូល)
- ផ្ទុក map តាម Image Menu Button នៃ **Bump Strength** — slider ជា multiplier
- Shaders ភាគច្រើនមាន **Bump Minimum** និង **Bump Maximum** សម្រាប់កំណត់ដែនកំណត់/shift/scale តម្លៃ map
- ⚠️ Bump មិនឃើញក្នុង Viewport ទេ — ឃើញតែ **ក្រោយពេល Render**

Displacement (ប្ដូររូបរាងពិត)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

ស្រដៀង bump ដែរ ប៉ុន្តែខុសគ្នាសំខាន់៖ bump គ្រាន់តែ **ក្លែង** ចំណែក displacement **ប្ដូររូបរាង mesh ពិតប្រាកដ** ពេល Render។ ឧទាហរណ៍ជញ្ជាំងឥដ្ឋ៖ bump សម្រាប់ភាពគ្រើមលើផ្ទៃឥដ្ឋនីមួយៗ · displacement សម្រាប់គម្លាតរវាងឥដ្ឋ (បាយអ)។

- **Displacement Map** = grayscale image៖ ``128, 128, 128`` = គ្មាន displacement · ស្រាលជាង = mesh លៀនចេញក្រៅ · ងងឹតជាង = mesh លៀនចូលក្នុង
- Shaders ខ្លះមាន **Minimum/Maximum Displacement** ដើម្បីកំណត់ចម្ងាយ displacement អតិបរមា (Minimum = អវិជ្ជមាន, Maximum = វិជ្ជមាន)

.. note:: ខ្នាតក្នុង Daz Studio៖ **1 unit = 1 សង់ទីម៉ែត្រ** — ចាំទុកពេលកំណត់តម្លៃ min/max displacement។ ហើយដូច bump — ឥទ្ធិពលឃើញតែក្រោយ Render។

UV Set
^^^^^^

លក្ខណៈសម្បត្តិ **UV Set** លើផ្ទៃកំណត់ថា UV set ណាត្រូវបានប្រើ។ សំខាន់ណាស់៖ **UV set និង image maps ត្រូវតែត្រូវគ្នា** — បើមិនដូច្នោះអ្នកនឹងទទួលបានការបំភ្លៃ និង seams។ UV set ល្អបង្រួមការយឺត (stretching) និងការបង្រួម (compression) ហើយដាក់ seams នៅកន្លែងដែលសមហេតុផល ឬលាក់។

ប្ដូរ UV set សម្រាប់ផ្ទៃមួយ ច្រើន ឬតួទាំងមូល៖ ក្នុងផ្ទាំង Surfaces ចុចលើបញ្ជីជ្រើស UV Set រួចជ្រើសពីបញ្ជីដែលមាន។

Material(s) Presets
-------------------

ការកំណត់ផ្ទៃនីមួយៗដោយដៃ (ផ្ទុក image maps កំណត់តម្លៃ...) អាចនឿយហត់។ ផលិតផលភាគច្រើនពី DAZ 3D Store ភ្ជាប់មកជាមួយ presets ដែលកំណត់តម្លៃ និងផ្ទុក image maps ជំនួសអ្នក — រួមគ្នាហៅថា **«Material»** ហើយ presets នោះហៅថា **«Material(s) Presets»**។ នេះជាវិធីងាយស្រួលបំផុតក្នុងការកំណត់ផ្ទៃគំរូ។

ការផ្ទុក Presets
~~~~~~~~~~~~~~~

ផ្ទុកបានពី ៣ កន្លែង៖ page **Presets** នៃផ្ទាំង Surfaces · ផ្ទាំង **Smart Content** · ផ្ទាំង **Content Library**។

Page Presets របៀបដំណើរការដូច Smart Content ដែរ — Category View នៅខាងឆ្វេង (ពង្រីក/បង្រួមបាន) · Asset View នៅខាងស្ដាំ។

.. important:: ត្រូវ **ជ្រើសតួ/វត្ថុជាមុន** ទើប presets លេចឡើង (ព្រោះវាត្រូវអនុវត្តលើវត្ថុក្នុងឆាក)។

ឧទាហរណ៍ជាមួយ Genesis 2 Female — តាមលំនាំដើមមានជម្រើសភ្នែក និងគ្រឿងសម្អាង (makeup) ជាច្រើន រួមទាំង texture ពេញខ្លួនឈ្មោះ **'Bree All'** (ការប្រើ 'Bree All' ស្ដារ materials ទៅសភាពដើម)។

.. tip:: អ្នកសិល្បៈជាច្រើនចាត់ទុក Material(s) Presets ជា **ចំណុចចាប់ផ្តើម** ប៉ុណ្ណោះ — បន្ទាប់ពីផ្ទុក preset កែលក្ខណៈសម្បត្តិលើ page Editor ដើម្បីរៀនពីឥទ្ធិពលរបស់វា។ វិធីរៀនល្អបំផុតមួយគឺ «វះកាត់» presets ដែលទិញពី DAZ 3D Store។

Surface Selection Tool
~~~~~~~~~~~~~~~~~~~~~~

ក្រៅពីជ្រើសក្នុងផ្ទាំង អាចជ្រើសផ្ទៃ **ផ្ទាល់ក្នុង Viewport**៖

#. បើកឧបករណ៍ពី toolbar (ចុចឆ្វេងលើរូបភាពតំណាង)
#. ដាក់ទ្រនិចលើតួ — ផ្ទៃក្រោមទ្រនិចនឹងលេចពណ៌ ហើយ **ឈ្មោះរបស់វាលេចក្បែរទ្រនិច**
#. ចុចឆ្វេង → ផ្ទៃនោះត្រូវបានជ្រើសក្នុងផ្ទាំង Surfaces (សង្កត់ Ctrl/Cmd សម្រាប់ជ្រើសច្រើន)

អត្ថប្រយោជន៍៖ ឃើញច្បាស់ថាតំបន់ណានៃគំរូជាផ្នែកនៃ surface នីមួយៗ និងជ្រើសបានទោះមិនដឹងឈ្មោះផ្ទៃ។

រក្សាទុក Material(s) Preset ផ្ទាល់ខ្លួន
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

#. ជ្រើសវត្ថុដែលចង់រក្សាទុក preset (ក្នុងផ្ទាំង Scene)
#. **File > Save As > Material(s) Preset…** → ផ្ទាំងសន្ទនា «Filtered Save» — ជ្រើសទីតាំង ដាក់ឈ្មោះ រួចចុច **Save**
#. ផ្ទាំងសន្ទនា **«Material(s) Preset Save Options»** លេចឡើង — ជ្រើសផ្ទៃដែលចង់រួម (ធីក/ដកធីក) និងលក្ខណៈសម្បត្តិក្រោមផ្ទៃនីមួយៗ (ចុចព្រួញដើម្បីពង្រីក)។ ឧទាហរណ៍៖ preset សម្រាប់តែភ្នែក → រួមតែផ្ទៃភ្នែក។
#. ចុច **Accept**

Preset ថ្មីលេចក្នុង page Presets (Surfaces pane), Smart Content ឬ Content Library — ក្រោម category **'Unassigned'** (ពេលជ្រើសវត្ថុដើម)។ ចុចពីរដង ឬអូសទម្លាក់ដើម្បីផ្ទុក។

Spot Render Tool — ត្រួតពិនិត្យរហ័ស
--------------------------------------

ការមើលជាមុនក្នុង Viewport ជាញឹកញាប់មិនគ្រប់គ្រាន់ដើម្បីឃើញថា materials នឹងលេចយ៉ាងណាពេល Render — លក្ខណៈសម្បត្តិផ្ទៃជាច្រើនមានឥទ្ធិពលតែ **ក្រោយ Render** ប៉ុណ្ណោះ ហើយការ Render ឆាកទាំងមូលចំណាយធនធាន និងពេលវេលាច្រើន។

**Spot Render Tool** ដំណោះស្រាយ៖ ចុចរូបភាពតំណាងរបស់វាក្នុង toolbar រួច **ចុចឆ្វេង + អូស** ក្នុង Viewport — ចតុកោណ marquee នឹងលេចឡើង ហើយ Daz Studio នឹង Render **តែផ្នែកក្នុង marquee** ដោយប្រើការកំណត់ Render បច្ចុប្បន្ន — លទ្ធផលលេចផ្ទាល់ក្នុង Viewport។

.. tip::

   ការបង្កើត materials ដែលមើលទៅពិតត្រូវការការអនុវត្ត និងបទពិសោធន៍ — វិធីល្អបំផុតគឺសាកល្បង និងពិសោធន៍។ ជំពូកបន្ទាប់ (:doc:`Shaping <shaping>`) សប្បាយជាង និងតិចបច្ចេកទេសជាង!
