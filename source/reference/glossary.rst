វចនានុក្រមពាក្យបច្ចេកទេស
===========================

.. meta::
   :description: វចនានុក្រមពាក្យបច្ចេកទេស Daz Studio ខ្មែរ-អង់គ្លេស ៦០+ ពាក្យ៖ Morph, Shader, Surface, Render, Depth of Field... Khmer-English glossary of Daz Studio technical terms.


.. raw:: html

   <p class="src-note">បកប្រែ និងចងក្រងពី៖ <a href="https://docs.daz3d.com/public/software/dazstudio/4/referenceguide/terms/start" target="_blank" rel="noopener">Terms (Glossary)</a> និងមាតិកានៃមគ្គុទ្ទេសក៍អ្នកប្រើប្រាស់ Daz Studio 4.x</p>

ពាក្យបច្ចេកទេសសំខាន់ៗដែលអ្នកនឹងជួបពេលប្រើ Daz Studio ៤.x — រៀបតាមលំដាប់អក្សរក្រម។ ពាក្យដើមរក្សាជាភាសាអង់គ្លេស ព្រោះវាជាពាក្យដែលលេចឡើងក្នុងចំណុចប្រទាក់កម្មវិធីផ្ទាល់។

.. list-table::
   :header-rows: 1
   :widths: 24 76

   * - ពាក្យ
     - អត្ថន័យ
   * - **Activity**
     - បរិបទការងារមួយក្នុងចំណុចប្រទាក់ (ឧ. 'Actors, Wardrobe & Props', 'Pose & Animate', 'Lights & Cameras', 'Render') — ប្ដូរតាមរយៈ Activity Tabs នៅលើ Activity Bar
   * - **Ambient Light**
     - ពន្លឺ «បរិយាកាស» — ឥទ្ធិពលស្មើៗគ្នាពីពន្លឺដែលលោតត្រឡប់ (bounced light) លើឆាក ផ្ទុយពីពន្លឺផ្ទាល់ពីប្រភពជាក់លាក់
   * - **Aspect Ratio**
     - សមាមាត្រទទឹង:កម្ពស់នៃរូបភាព render (ឧ. 4:3, 16:9) — កំណត់ក្នុងការកំណត់ Dimensions
   * - **Auto-Fit**
     - សកម្មភាពដែលព្យាយាម fit សម្លៀកបំពាក់ដែលរចនាសម្រាប់តួមួយ ទៅតួផ្សេង — លទ្ធផលប្រែប្រួល
   * - **Bank**
     - ការរមៀល (roll) ទិដ្ឋភាពទៅឆ្វេង/ស្ដាំ ជុំវិញអ័ក្សនៃការមើល — ធ្វើដោយ Ctrl/Cmd + ចុចស្ដាំ + អូសលើ Viewport control
   * - **Bounding Box**
     - ប្រអប់បន្ទាត់ជុំវិញវត្ថុ បញ្ជាក់ថាវាកំពុងត្រូវបានជ្រើស
   * - **Bump Map**
     - Grayscale image map ដែលក្លែងភាពគ្រើម/លៀនលើផ្ទៃ ដោយមិនប្ដូរ mesh — ឃើញតែក្រោយ Render
   * - **Camera(s) Preset**
     - Preset ដែលផ្ទុកកាមេរ៉ាមួយ ឬច្រើនចូលឆាក — តាមលំនាំដើមជំនួសកាមេរ៉ាទាំងអស់ (សង្កត់ Ctrl/Cmd ដើម្បីជ្រើស 'Add')
   * - **CMS (Content Management Service)**
     - សេវាគ្រប់គ្រងមាតិកាដែលត្រូវដំឡើង និងដំណើរការ ទើប Smart Content និងការរុករកតាម Product/Category ដំណើរការត្រឹមត្រូវ
   * - **Conforming / Fitting**
     - ដំណើរការដែលសម្លៀកបំពាក់ ឬសក់ «ដើរតាម» ចលនារបស់តួ — កំណត់ដោយលក្ខណៈសម្បត្តិ 'Fit To' ក្នុង Parameters > General > Misc
   * - **Content Type Indicator**
     - សញ្ញាពណ៌+អក្សរនៅជ្រុងរូបភាពតំណាងក្នុង Smart Content៖ បៃតង=ផ្ទុកវត្ថុថ្មី · លឿង=កែវត្ថុស្រាប់ · ខៀវ=អាស្រ័យការជ្រើស · ក្រហម=ជំនួសវត្ថុប្រភេទដូចគ្នា · ម៉ាហ្សង់តា=ប្រភេទទូទៅពេក
   * - **Depth of Field (DoF)**
     - លក្ខណៈសម្បត្តិកាមេរ៉ា — ពេលបើក អ្វីក្រៅតំបន់ focus នឹងព្រិល (blur) · គ្រប់គ្រងដោយ Focal Distance និង F/Stop
   * - **Diffuse**
     - ការចំណាំងផ្លាតពន្លឺខ្ចាត់ខ្ចាយគ្រប់ទិស — «Diffuse Color» គឺពណ៌ [matte] ដែលយើងមើលឃើញនៃផ្ទៃ
   * - **Displacement Map**
     - Grayscale image map ដែល **ប្ដូររូបរាង mesh ពិតប្រាកដ** ពេល Render (ខុសពី bump ដែលគ្រាន់តែក្លែង) · 1 unit = 1 សង់ទីម៉ែត្រ
   * - **Dolly**
     - ការផ្លាស់ទីទិដ្ឋភាពចូល/ចេញ និងឆ្វេង/ស្ដាំ ក្នុងប្លង់ស្របនឹងឥត · **Dolly Zoom** = zoom ដោយផ្លាស់ទីទិដ្ឋភាពទាំងមូលជិត/ឆ្ងាយពីវត្ថុ
   * - **DSON / .duf**
     - ទម្រង់ឯកសារ native របស់ Daz Studio — សង្កត់ Ctrl/Cmd ពេលផ្ទុកដើម្បីបើកជម្រើសផ្ទុកលម្អិត
   * - **F/Stop**
     - លក្ខណៈសម្បត្តិកាមេរ៉ា — កំណត់ចម្ងាយរវាងប្លង់ DoF ជិត និងឆ្ងាយ (តំបន់ច្បាស់)។ តម្លៃធំ = តំបន់ច្បាស់ធំ
   * - **Figure**
     - តួអង្គ 3D (មនុស្ស សត្វ ជាដើម) ដែលមាន skeleton និងអាច pose បាន — ឧ. Genesis, Genesis 2 Female
   * - **Focal Length**
     - លក្ខណៈសម្បត្តិកាមេរ៉ា — កំណត់ field of view (zoom)។ តម្លៃខ្លាំងបំភ្លៃ perspective
   * - **Focal Point**
     - ចំណុចកណ្ដាលដែល Viewport controls (orbit, zoom) ធ្វើការជុំវិញ — ប្ដូរទៅកណ្ដាល bounding box ពេល Frame វត្ថុ
   * - **Follower**
     - វត្ថុដែល «ដើរតាម» វត្ថុផ្សេង (សម្លៀកបំពាក់ សក់ conformed នឹងតួ)
   * - **Genesis**
     - ប្រព័ន្ធតួអង្គមូលដ្ឋានរបស់ DAZ 3D ដែលមានសមត្ថភាព morph ខ្លាំង — Genesis, Genesis 2, 3, 8, 9...
   * - **Glossiness**
     - លក្ខណៈសម្បត្តិផ្ទៃ — កំណត់ **ទំហំ** នៃ specular highlight (រលងខ្លាំង = highlight តូច និងមុត)
   * - **Headlamp Lighting**
     - ពន្លឺលំនាំដើម «ក្បាល» — Daz Studio ប្រើពេលឆាកគ្មានពន្លឺផ្សេង · ល្អសម្រាប់ preview ប៉ុន្តែមិន realistic · បិទស្វ័យប្រវត្តិពេលផ្ទុកពន្លឺ
   * - **Image Map (Texture Map)**
     - រូបភាព ២ វិមាត្រដែល «រុំ» ជុំវិញ surface ដើម្បីផ្ដល់ពណ៌/ព័ត៌មានលម្អិត — គាំទ្រ .jpg, .png, .bmp, .tiff · ផ្ទុកតាម Image Menu Button
   * - **Install Manager**
     - កម្មវិធីរបស់ DAZ 3D សម្រាប់ទាញយក និងដំឡើងមាតិកាពីគណនី DAZ Store (`ឯកសារ <https://docs.daz3d.com/public/software/install_manager/start>`_)
   * - **Layout**
     - ការរៀបចំធាតុចំណុចប្រទាក់ទាំងមូល — មាន ៤ ស្រាប់៖ Full Service [Beta], Hollywood Blvd (លំនាំដើម), Self Serve, City Limits · រក្សាទុកផ្ទាល់ខ្លួនបាន (F4)
   * - **Light(s) Preset**
     - Preset ដែលផ្ទុកពន្លឺមួយ ឬមួយឈុត — តាមលំនាំដើមជំនួសពន្លឺទាំងអស់ (Ctrl/Cmd = ជម្រើស Add)
   * - **Linear Point Light**
     - ពន្លឺចំណុចដែលមិនដើរតាមច្បាប់ inverse-square — អ្នកកំណត់ Falloff Start/End ផ្ទាល់ខ្លួន (បាល់ពីរក្នុង Viewport)
   * - **Material(s) Preset**
     - Preset ដែលកំណត់លក្ខណៈសម្បត្តិផ្ទៃ (Materials) ទាំងមូល — វិធីងាយបំផុតក្នុងការផ្លាស់ប្ដូររូបរាងផ្ទៃគំរូ
   * - **Mesh**
     - បណ្ដាញ polygon ដែលបង្កើតជាជាក់លាក់នៃវត្ថុ 3D
   * - **Morph (Morph Target)**
     - ទិន្នន័យដែលកំណត់ពីរបៀប vertices នៃវត្ថុផ្លាស់ទីដើម្បីប្ដូររូបរាង — បង្ហាញជា sliders ក្នុងផ្ទាំង Shaping
   * - **Node / Bone**
     - ធាតុមួយក្នុងលំដាប់ថ្នាក់ (hierarchy) នៃតួ — អាចជ្រើស និង pose ដាច់ដោយឡែក (ឧ. ដៃ ជើង ម្រាម) · **Root Node** = ថ្នាក់កំពូល («skeleton»)
   * - **Opacity Map**
     - Grayscale image map ដែលកំណត់ភាពថ្លា៖ ខ្មៅ=ថ្លា 100% · ស=opaque 100% (ជារឿយៗហៅច្រឡំថា «transparency map»)
   * - **Orbit**
     - ការវិលជុំវិញ focal point នៃទិដ្ឋភាព — ចុចឆ្វេង + អូសលើ Viewport control ឬ Camera Cube
   * - **Orthographic Views**
     - ទិដ្ឋភាពមុំកែង ៩០° គ្មាន perspective (Front, Left, Right, Back, Top, Bottom) — សម្រាប់តម្រង់វត្ថុឱ្យជាក់លាក់
   * - **Pane**
     - ផ្ទាំងមុខងារមួយនៃចំណុចប្រទាក់ (Scene, Smart Content, Parameters, Surfaces, Shaping, Posing, Lights, Cameras, Render Settings, Content Library...) — អាច dock/float និងរៀបចំជាក្រុមបាន
   * - **Pan**
     - ការផ្លាស់ទីទិដ្ឋភាពឆ្វេង/ស្ដាំ និងលើ/ក្រោម ក្នុងប្លង់ស្របនឹងការមើល
   * - **Parent / Child**
     - ទំនាក់ទំនងរវាងវត្ថុ — កូនដើរតាមម្ដាយពេលផ្លាស់ទី/បង្វិល/ប្ដូរទំហំ ប៉ុន្តែម្ដាយមិនដើរតាមកូនទេ · បង្កើតដោយអូសកូនទៅលើម្ដាយក្នុងផ្ទាំង Scene
   * - **Perspective View**
     - ទិដ្ឋភាពលំនាំដើម «Director's Viewfinder» — មើលឆាកជា 3D ដោយគ្មានកាមេរ៉ាពិត · មិនណែនាំសម្រាប់ final render
   * - **Pin (Pinning)**
     - ការ «ខ្ទាស់» ឆ្អឹងឱ្យនៅនឹងថ្កល់ពេល pose (soft pin — អាចផ្លាស់ទីបើចាំបាច់) — មានក្នុង Pinning Options Menu នៃ Pose Tool
   * - **Point Light**
     - ពន្លឺចេញពីចំណុចតែមួយគ្រប់ទិស (ដូចអំពូល/ទៀន) — មានតែ translation ដែលសំខាន់ · អាំងតង់ស៊ីតេទាប
   * - **Pose Preset**
     - Preset កាយវិការកំណត់ជាមុន — អនុវត្តលើតួភ្លាមៗ · ពេលរក្សាទុក ដកធីក group 'General' ក្រោម root node ដើម្បីកុំឱ្យផ្លាស់ទីតួទាំងមូល
   * - **Prop**
     - វត្ថុស្តាទិចក្នុងឆាក (មិន pose បាន) — អាច parent ទៅផ្នែករាងកាយរបស់តួបាន
   * - **Region**
     - តំបន់រាងកាយដែល morphs ត្រូវបានកំណត់ទៅ (Arms, Legs, Hands, Face, Actor...) — ជ្រើសដោយ Region Navigator Tool
   * - **Render**
     - ដំណើរការបំលែងឆាក 3D ទៅជារូបភាព ២ វិមាត្រ/animation · **Render Engine** = ម៉ាស៊ីនគណនា (software ឬ OpenGL) · **Spot Render** = render តែផ្ទៃដែលជ្រើសក្នុង Viewport
   * - **Render Settings Preset**
     - Preset រក្សាទុក/ផ្ទុកការកំណត់ Render ទាំងអស់ (General + Advanced) — ផ្ទុកពេលណាជំនួសការកំណត់បច្ចុប្បន្នទាំងអស់
   * - **Scene**
     - ឆាក — អ្វីៗទាំងអស់ដែលផ្ទុកក្នុងឯកសារមួយ (តួ សម្លៀកបំពាក់ props ពន្លឺ កាមេរ៉ា) · **Scene Pane** = បញ្ជីវត្ថុទាំងអស់ជាលំដាប់ថ្នាក់
   * - **Shader**
     - កម្មវិធីដែល Render Engine ដំណើរការសម្រាប់ចំណុចនីមួយៗលើផ្ទៃ ដើម្បីគណនាពណ៌/opacity ចុងក្រោយ · ៥ ប្រភេទ៖ Surface, Light, Volume, Imager, Displacement · «Shader Preset» ≠ shader
   * - **Shading Rate**
     - ការកំណត់ render — លម្អិតធៀបនឹងល្បឿន (ទាប=លម្អិតខ្ពស់/យូរ · ខ្ពស់=លឿន/លម្អិតតិច) · លំនាំដើម 1.00
   * - **Smart Content**
     - ផ្ទាំងផ្ទុកមាតិកាតាម **បរិបទ** — បង្ហាញតែមាតិកាស្របនឹងការជ្រើសបច្ចុប្បន្ន · មាន ២ pages៖ Files និង Products · ត្រូវការ CMS
   * - **Specular**
     - ការចំណាំងផ្លាតពន្លឺទៅទិសតែមួយ — «Specular Color» = ពណ៌ highlight · «Specular Strength» = អាំងតង់ស៊ីតេ highlight
   * - **Spotlight**
     - ពន្លឺរាងកោណ — ទាំងទីតាំង និងទិសដៅសំខាន់ · Spread Angle កំណត់ទទឹងកោណ
   * - **Surface**
     - ផ្នែករងនៃគំរូ 3D (ក្រុម polygons) ដែលចែករំលែកលក្ខណៈសម្បត្តិរួម — Genesis មាន ២៦ surfaces · **Surface Selection Set** = ក្រុមផ្ទៃកំណត់ជាមុន
   * - **UV Set**
     - សំណុំកូអរដូនេ ២ វិមាត្រដែលកំណត់ពីរបៀប image map «រុំ» ជុំវិញគំរូ ៣ វិមាត្រ — UV set និង image maps ត្រូវតែត្រូវគ្នា
   * - **Universal Tool**
     - ឧបករណ៍ពហុមុខងារ — translate/rotate/scale វត្ថុ និង nodes ក្នុង Viewport ដោយ manipulator (ព្រួញ ធ្នូ គូប)
   * - **Viewport**
     - ផ្ទៃមើលឆាក 3D ធំនៅកណ្ដាលចំណុចប្រទាក់ — មាន Viewport Controls នៅជ្រុងខាងលើស្ដាំ
   * - **3-Point Lighting**
     - បច្ចេកទេសបំភ្លឺស្តង់ដារ៖ **Key Light** (ពន្លឺមេ ~100%) + **Fill Light** (បំពេញកន្លែងងងឹត ~40%) + **Rim Light** (ពីក្រោយ ~120% បង្កើតគែមលេចធ្លោ)
   * - **WIP**
     - «Work In Progress» — ទំព័រ/មាតិកាកំពុងសាងសង់មិនទាន់ពេញលេញក្នុងឯកសារដើម
