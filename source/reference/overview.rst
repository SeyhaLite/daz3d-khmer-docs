ផ្នែកទាំង ៦ នៃ Reference Guide
--------------------------------

.. list-table::
   :header-rows: 1
   :widths: 26 74

   * - ផ្នែក
     - ខ្លឹមសារ
   * - **Terms (Glossary)**
     - លិបិក្រម និងវចនានុក្រមនៃពាក្យបច្ចេកទេសដែលអ្នកអាចជួបពេលប្រើ Daz Studio (មើល :doc:`វចនានុក្រមខ្មែរ <glossary>`)
   * - **User Interface (UI)**
     - ពន្យល់ធាតុចំណុចប្រទាក់ **ទាំងអស់** របស់ Daz Studio 4.x — លំហូរព័ត៌មានដើរពី «ទូទៅ និងសាមញ្ញ» ទៅ «ជាក់លាក់ និងស្មុគស្មាញ» (មើល :doc:`ចំណុចប្រទាក់អ្នកប្រើប្រាស់ <interface>`)
   * - **Plugins**
     - ព័ត៌មានអំពី plug-ins (អាចទិញពី `Daz 3D Store <https://www.daz3d.com/software/plugins-utilities/>`_) ដែលពង្រីកសមត្ថភាព Daz Studio
   * - **Technical Articles**
     - អត្ថបទបច្ចេកទេសជាច្រើនពាក់ព័ន្ធនឹង Daz Studio
   * - **Scripting**
     - ព័ត៌មានអំពីភាសា scripting, Scripting API និងគំរូជាច្រើនដើម្បីចាប់ផ្តើមសរសេរ script ផ្ទាល់ខ្លួនសម្រាប់ Daz Studio
   * - **User Interface Styling**
     - ការបត់បែនរូបរាង/ពណ៌នៃចំណុចប្រទាក់
