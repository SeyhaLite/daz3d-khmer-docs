មគ្គុទ្ទេសក៍ចាប់ផ្តើមរហ័ស — Barefoot Dancer

បកប្រែពី៖ QuickStart Guide — Barefoot Dancer · វីដេអូ៖ Quickstart Guide - Barefoot Dancer

មគ្គុទ្ទេសក៍នេះណែនាំជំហានម្ដងមួយៗ ដើម្បីបង្កើតឆាក Barefoot Dancer ឡើងវិញ — គោលបំណងគឺផ្ដល់ចំណេះដឹងមូលដ្ឋានដែលអ្នកអាចពង្រីកបន្តបាន។ វាមិនពន្យល់ស៊ីជម្រៅអំពីដំណើរការនីមួយៗទេ — សម្រាប់ព័ត៌មានលម្អិត សូមមើលមគ្គុទ្ទេសក៍អ្នកប្រើប្រាស់ (ជំពូក ១–៨ នៃគេហទំព័រនេះ)។

ដើម្បីអនុវត្តតាមមគ្គុទ្ទេសក៍នេះ អ្នកត្រូវការ៖

Tip

នៅកំណែថ្មីៗ មាតិកា Starter Essentials សម្រាប់តួជំនាន់ក្រោយ (Genesis 8/9) ក៏អាចប្រើតាមជំហានដូចគ្នានេះដែរ — គ្រាន់តែជ្រើសមាតិកាដែលត្រូវនឹងតួរបស់អ្នក។

ជំហានទី ១ — ត្រៀម Interface Layout

Daz Studio មាន «Interface Layouts» ជាច្រើន។ មេរៀននេះប្រើ layout Hollywood Blvd ដែលជា layout លំនាំដើម។ បើនេះជាលើកទី ១ របស់អ្នកក្នុងការបើក Daz Studio (ឬអ្នកមិនធ្លាប់ប្ដូរ layout) អ្នកមិនចាំបាច់ធ្វើអ្វីបន្ថែមទេ។

បើធ្លាប់ប្ដូរ layout រួចហើយ សូមប្ដូរទៅ Hollywood Blvd វិញ៖ ចូល Window > Workspace > Select Layout… រួចជ្រើស Hollywood Blvd ពីម៉ឺនុយធ្លាក់ចុះ ហើយចុច Accept។

Layout នេះបែងចែកជា «Activities» ជាច្រើន — អ្នកអាចប្ដូររវាង Activities ដោយចុចលើ «Activity Tabs» នៅផ្នែកខាងលើនៃ Main Window។

ជំហានទី ២ — ផ្ទុកតួ សម្លៀកបំពាក់ សក់ និងបរិស្ថាន

ចាប់ផ្តើមដោយចូល Activity Actors, Wardrobe & Props (ចុចលើ Activity tab)។

តួអង្គ (Actor)

  1. បើកផ្ទាំង Smart Content ដោយចុចលើ tab «Smart Content» នៅខាងឆ្វេងនៃចំណុចប្រទាក់ ហើយប្រាកដថា page Files នៅផ្នែកខាងលើត្រូវបានជ្រើស។

  2. ពង្រីក category Figures ដោយចុចព្រួញនៅខាងឆ្វេង រួចពង្រីក subcategory People និងជ្រើស Female។

  3. រូបភាពតំណាងនឹងលេចឡើងនៅជួរខាងស្ដាំ។ ចុចពីរដងលើ FIGURE - Barefoot Dancer ដើម្បីផ្ទុកតួចូលឆាក — អ្នកនឹងឃើញវាលេចឡើងក្នុង Viewport ជាមួយ Bounding Box ដែលបញ្ជាក់ថាវាកំពុងត្រូវបានជ្រើស។

សម្លៀកបំពាក់ (Wardrobe)

ពង្រីក category Wardrobe រួចជ្រើស Full-Body។ ចុចពីរដងលើ CLOTHING - Barefoot Dancer ដើម្បីផ្ទុកសម្លៀកបំពាក់ ឬអូសរូបភាពតំណាងទៅដាក់លើតួក្នុងឆាកក៏បាន។

សក់ (Hair)

ពង្រីក category Hair រួចជ្រើស subcategory Short។ ផ្ទុក HAIR - Toulouse Hair ដោយចុចពីរដង ឬអូសទម្លាក់លើតួ Barefoot Dancer។

បរិស្ថាន (Environment)

  1. ដំបូង ដកការជ្រើស (Deselect) តួសិន — ចុចនៅកន្លែងណាមួយក្នុង Viewport ដែលមិនចំតួ ឬសម្លៀកបំពាក់។

  2. ពង្រីក category Ready to Render រួចជ្រើស Architecture។

  3. ចុចពីរដងលើ ENVIRONMENT - Barefoot Dancer ដើម្បីផ្ទុកបរិស្ថានចូលឆាក។

Important

ការជ្រើសវត្ថុក្នុងឆាកសំខាន់ណាស់ — រាល់ពេលចង់កែវត្ថុណាមួយ អ្នកត្រូវជ្រើសវាជាមុនសិន។ ដើម្បីជ្រើសសក់ ឧទាហរណ៍ ចុចស្ដាំលើសក់ក្នុង Viewport រួចជ្រើស Select 'ToulouseHR' ពី Context Menu — Bounding Box នឹងលេចឡើងជុំវិញសក់។

ជំហានទី ៣ — កែរូបរាងសក់ (Shaping)

  1. ចុច tab Shaping នៅខាងឆ្វេងនៃចំណុចប្រទាក់ (ផ្ទាំងនេះជាប់គ្នានឹង Smart Content)។

  2. ចុច Presets នៅផ្នែកខាងលើនៃផ្ទាំង ដើម្បីបើក page Presets។

  3. ចុច category Apply នៅខាងឆ្វេង រួចចុចពីរដងលើរូបភាពតំណាង HAIR SHAPE - Toulouse Hair នៅខាងស្ដាំ ដើម្បីអនុវត្ត។

ជំហានទី ៤ — បង្កើតកាយវិការ (Pose)

  1. បើក Activity Pose & Animate ដោយចុចលើ Activity tab។

  2. ជ្រើសតួ Barefoot Dancer៖ ដាក់ទ្រនិចកណ្ដុរលើតួរហូតដល់វាលេចពណ៌ រួចចុចពីរដង (ឬចុចស្ដាំ រួចជ្រើស Select 'Genesis 2 Female' - Dbl Click)។

  3. បើកផ្ទាំង Posing (tab នៅខាងឆ្វេង) រួចចុច Presets។

  4. ពង្រីក category By Function រួចជ្រើស subcategory Running។

  5. ចុចពីរដងលើ Pose - Genesis 2 Barefoot Dancer — តួនឹងផ្លាស់ទៅកាយវិការថ្មី។

ជំហានទី ៥ — ពន្លឺ និងកាមេរ៉ា

បើក Activity Lights & Cameras។

ពន្លឺ

  1. ចុច tab Lights នៅខាងឆ្វេង រួចចុច Presets។

  2. ពង្រីក category Lights រួចជ្រើស subcategory Other។

  3. ចុចពីរដងលើ LIGHTS - Barefoot Dancer ដើម្បីផ្ទុក Light Preset។

កាមេរ៉ា

  1. ចុច tab Cameras (ផ្ទាំងជាប់គ្នានឹង Lights) រួចចុច Presets។

  2. ជ្រើស category Barefoot Dancer នៅជួរខាងឆ្វេង — មានរូបភាពតំណាង Camera Preset ពីរ។

  3. ចុចពីរដងលើ CAMERA 1 - Barefoot Dancer។ ទិដ្ឋភាពរបស់អ្នកនឹងប្ដូរភ្លាម — អ្នកកំពុងមើលតាមរយៈកាមេរ៉ាដែលទើបផ្ទុក។

ជំហានទី ៦ — ផ្ទៃខាងក្រោយ (Backdrop)

ឆាកអាចនៅសល់ចន្លោះទទេនៅផ្ទៃខាងក្រោយ (អ្នកអាចឃើញពណ៌ខៀវនៅជ្រុងខាងឆ្វេងលើ)។ Backdrop Image នឹងបំពេញចន្លោះទាំងនោះ៖

  1. ចូល Edit > Backdrop… ដើម្បីបើកផ្ទាំងសន្ទនា «Backdrop Options»។

  2. ចុចប៊ូតុងក្បែរស្លាក Image: រួចជ្រើស Browse…។

  3. រុករកទៅកន្លែងដំឡើងផលិតផល Genesis 2 Female Starter Essentials — តាមលំនាំដើម៖

    • Windows: C:/Users/Public/Documents/My DAZ 3D Library

    • Mac: /Users/Public/Documents/My DAZ 3D Library

  4. បើកថត Runtime → Textures → DAZ → Backdrops រួចចុចពីរដងលើឯកសារ dusk sky។

  5. ចុច Accept ដើម្បីបិទផ្ទាំងសន្ទនា និងផ្ទុករូបភាពផ្ទៃខាងក្រោយ។

ជំហានទី ៧ — Render ឆាក

  1. បើក Activity Render ដោយចុចលើ Render activity tab។

  2. បើកផ្ទាំង Content Library នៅខាងស្ដាំ (មាតិកាទាំងអស់ក្នុង Smart Content ក៏អាចផ្ទុកពីទីនេះបានដែរ)។

  3. ក្នុង Container View នៅផ្នែកខាងលើ រុកទៅ DAZ Studio Formats > My DAZ 3D Library > DAZ Studio Tutorials > Genesis 2 Barefoot Dancer។

  4. អ្នកនឹងឃើញរូបភាពតំណាង Render Settings បី — ចុចពីរដងលើ Render Settings Low - barefoot Dancer សម្រាប់ការ Render លឿន (Medium ឬ High ក៏បាន ប៉ុន្តែចំណាយពេលយូរជាង)។

  5. បើកផ្ទាំង Render Settings (tab នៅខាងឆ្វេង) រួចចុច General — Preset ដែលទើបផ្ទុកបានកំណត់ទំហំរូបភាព 700 x 910 ភីកសែល។ អ្នកអាចប្ដូរទំហំតាមប្រអប់ Dimensions។

  6. ចុចប៊ូតុង Render ពណ៌បៃតងនៅជ្រុងខាងលើស្ដាំនៃផ្ទាំង Render Settings ដើម្បីចាប់ផ្តើម (ឬប្រើផ្លូវកាត់ Ctrl + R / Cmd + R)។

Note
