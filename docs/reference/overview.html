ផ្នែក

ខ្លឹមសារ

Terms (Glossary)

លិបិក្រម និងវចនានុក្រមនៃពាក្យបច្ចេកទេសដែលអ្នកអាចជួបពេលប្រើ Daz Studio (មើល វចនានុក្រមខ្មែរ)

User Interface (UI)

ពន្យល់ធាតុចំណុចប្រទាក់ ទាំងអស់ របស់ Daz Studio 4.x — លំហូរព័ត៌មានដើរពី «ទូទៅ និងសាមញ្ញ» ទៅ «ជាក់លាក់ និងស្មុគស្មាញ» (មើល ចំណុចប្រទាក់អ្នកប្រើប្រាស់)

Plugins

ព័ត៌មានអំពី plug-ins (អាចទិញពី Daz 3D Store) ដែលពង្រីកសមត្ថភាព Daz Studio

Technical Articles

អត្ថបទបច្ចេកទេសជាច្រើនពាក់ព័ន្ធនឹង Daz Studio

Scripting

ព័ត៌មានអំពីភាសា scripting, Scripting API និងគំរូជាច្រើនដើម្បីចាប់ផ្តើមសរសេរ script ផ្ទាល់ខ្លួនសម្រាប់ Daz Studio
