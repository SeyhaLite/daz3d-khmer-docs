Daz Studio 4.x — ឯកសារជាភាសាខ្មែរ

ការបកប្រែជាភាសាខ្មែរដោយសហគមន៍ នៃឯកសារ Daz Studio 4.x (កំណែចេញផ្សាយទូទៅថ្មីបំផុត 4.24.0.4) ពី DAZ 3D Documentation Center។

Daz Studio គឺជាស្ទូឌីយោថតរូប និងភាពយន្តនិម្មិតពេញលេញ — ពីរូបភាពពិតដល់រវើរវាយ។ ឯកសារនេះគ្របដណ្ដប់មគ្គុទ្ទេសក៍អ្នកប្រើប្រាស់ទាំង ៨ ជំពូក និងឯកសារយោងសំខាន់ៗ។

Note

គេហទំព័រនេះមិនមែនជាឯកសារផ្លូវការរបស់ DAZ 3D ទេ។ មាតិកាដើមស្ថិតក្រោមអាជ្ញាបណ្ណ CC BY 3.0។ ឈ្ោះម៉ឺនុយ ប៊ូតុង និងផ្ទាំង (Panes) ត្រូវបានរក្សាជាភាសាអង់គ្លេស ដើម្បីឱ្យស្របនឹងកម្មវិធីជាក់ស្ដែង។
